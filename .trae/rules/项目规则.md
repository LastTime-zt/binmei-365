## APK 发版流程（重要）
- 上传新版 `AutoAnswer.apk` 时，必须先删除 Release 上的所有旧版 Release 和旧资产，再上传新版
- 下载链接保持固定不变，永远只有一个：`https://github.com/LastTime-zt/binmei-365/releases/latest/download/AutoAnswer.apk`
- 上传脚本参考：`license-service` 目录下的发版脚本（先删旧 Release → 创建/更新 latest Release → 删旧资产 → 上传新 APK → 验证 latest）
- **管理器 APK（AdminManager.apk）永远禁止上传到 GitHub（仓库/Release 均不行）**：管理器内置管理员能力，仅限本地分发（微信/网盘私下发给自己的管理手机），不得对外公开下载

## APK 下载镜像（自动更新兜底）
APP 内检查更新/下载必须带镜像兜底，镜像列表（前缀拼接）：
1. 直连：`https://github.com/LastTime-zt/binmei-365/releases/latest/download/AutoAnswer.apk`
2. `https://ghfast.top/https://github.com/...`（同上 URL 前加前缀）
3. `https://mirror.ghproxy.com/https://github.com/...`
4. `https://gh-proxy.com/https://github.com/...`

规则：直连失败自动依次尝试镜像；新增涉及 GitHub 下载的功能（APK 更新、题库下载、云端激活校验等）都必须实现同样的镜像回退逻辑。
